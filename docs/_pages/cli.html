User guide

CLI reference

cli.py runs a grading session from a terminal or in CI. It uses the same GradingService as the web app and writes the same session to results/.

usage: musa-grader [-h] {grade,sessions,rubrics} ...

grade

Grade a folder of submissions or a Canvas export ZIP.

python cli.py grade SUBMISSIONS [--rubric PATH] [--data PATH]... [--mode {docker,local}]
                    [--image IMAGE] [--timeout SECONDS] [--cell-timeout SECONDS]
                    [--confidence-threshold FLOAT]
ArgumentDefaultDescription
SUBMISSIONSrequiredA submissions folder or a Canvas export ZIP.
--rubricrubrics/hw1.yamlThe rubric to grade against.
--data PATHnoneAn assignment data file to place into every submission. Repeat the flag for several files. Students submit notebooks only, so Assignment 1 needs this.
--modedockerdocker runs each notebook in the sandbox image. local runs student code on this machine without isolation.
--imagemusa-grader:latestThe sandbox image for docker mode.
--timeout600Whole-notebook timeout in seconds. A rubric's execution_timeout_seconds raises it, never lowers it.
--cell-timeout300Per-cell timeout in seconds.
--confidence-threshold0.8Items graded below this confidence go to the review queue.

Before grading, the command prints warning: lines from GradingService.preflight(). Examples: no data file set for an assignment that needs one, a data path that does not exist, or one of Assignment 3's five files missing. If --mode docker is given and Docker is not running, it exits with status 2.

Examples

# Assignment 1 in the sandbox, with the class's Zillow file
python cli.py grade examples/submissions --mode docker --data examples/data/zillow_zhvi.csv

# Assignment 2: no data, graded from saved outputs
python cli.py grade examples/hw2_submissions --rubric rubrics/hw2.yaml

# Assignment 3 with a longer budget for the raster work
python cli.py grade canvas_export.zip --rubric rubrics/hw3.yaml --timeout 1800 --cell-timeout 1800

sessions

List saved grading sessions in results/: session id, assignment, submission count and last update.

python cli.py sessions

rubrics

List every rubric in rubrics/ that parses, as assignment_id path. CI runs this to check that every rubric loads.

python cli.py rubrics

Exit codes

CodeMeaning
0Success. Submissions may still be flagged for review.
2Rubric not found, or docker mode requested while Docker is unavailable.
