grader.rubric

YAML rubric loading (design.md section 20).

A rubric file declares the assignment, its point breakdown, and per-item config blocks. Expected values (Center City ZIPs, tolerances, the final answer) live here rather than in code so a TA can correct them against the official solution without touching Python.

Parse and validate a rubric YAML file.

Raises RubricError when the file is missing or unparsable, assignment.id is absent, the rubric is empty, an item id is missing or duplicated, an item type is unknown, or the item points do not add up to total_points.
