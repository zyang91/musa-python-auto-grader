assignments.hw4

Assignment 4 autograder — street networks and web scraping.

This assignment is graded without running the notebook (execution: never in rubrics/hw4.yaml). Every step of it talks to a server that is not ours — ArcGIS Open Data for the planning districts, the OpenStreetMap Overpass API for the street network, and five pages of Craigslist through a real browser — so a re-run would repeat all of those requests once per student. The service starts no kernel, container or browser for these submissions in any execution mode.

What is graded instead is the file the student handed in, read two ways:

  • The code they wrote. Lines the template already provides are set aside first, cell by cell (SubmittedCode), so the scaffold — the driver.get(url) and pd.concat inside the provided scraping loop, the def format_price(price_string): stub — earns nothing by being left in place. Each step is then a list of requirements in the rubric, a regex each, so a TA can widen one without touching Python.
  • The outputs their own run saved. The crash count, the scraping log, the results table, the histograms, the Folium map and the Altair spec are all in the notebook as the student ran it. Reference numbers come only from the assignment text ("about 3,750 crashes", 120 listings a page) and only raise confidence; a number outside its range sends an item to a person, it never costs points on its own.

The single exception is 2.5: the three format_* functions are cut out of the notebook and called on their own in the network-less Docker sandbox (grader/function_sandbox.py). Nothing else from the notebook goes with them.

Review policy as elsewhere: full marks when the evidence is there, and anything short of full marks reaches a person (grader/scoring.py).
