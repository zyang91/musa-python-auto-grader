assignments.hw5

Assignment 5 autograder — Yelp restaurants and census income.

Like Assignment 4, this assignment is graded without running the notebook (execution: never in rubrics/hw5.yaml). 1.1 queries the Census API through cenpy and 1.2 downloads TIGER tracts through pygris, so a re-run would repeat both downloads once per student. And the restaurants come from the Yelp Dataset Challenge, 8 GB in full: a notebook that reads the full dump rather than the 400 KB Philadelphia extract would take minutes and exhaust the grading machine's memory. Nothing here opens a data file — not the extract, not the dump. A notebook that reads the dump is named in 1.3's feedback, not penalised.

What is graded is the file the student handed in, read the way HW4 reads it (HW4Grader supplies the shared machinery): the code they wrote, and the outputs their own run saved. The one difference is how code is assigned to a step. The template has a ### 1.x heading above each step's empty cell, so each code cell is graded under the heading it sits beneath — otherwise the merge written for 1.5 would also satisfy 1.2's merge.

Reference numbers — 7,350 restaurants, Philadelphia's ~408 tracts — only raise confidence; a number outside its range sends an item to a person.
