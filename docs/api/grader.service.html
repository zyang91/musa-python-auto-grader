grader.service

The grading service the UI talks to.

Streamlit never calls the executor or the rubric engine directly (design.md §4): it hands a source and a config to this service and receives progress snapshots and a GradingSession back.

Methods

execution_config(rubric: 'Rubric | None' = None) -> ExecutionConfig #[source]

Execution limits, raised if the assignment declares it needs longer.

A rubric's execution_timeout_seconds is assignment knowledge, not a preference: Assignment 3 reads a 24 MB GeoJSON, joins 34,108 points and masks a ten-band raster twice, and cutting it short times out the whole class at once. So it acts as a floor on the configured timeout, never as a cap — a TA who raises the limit keeps their value.

class GradingService(rubric: Rubric, settings: GraderSettings | None = None, qualitative_grader: Any | None = None) #[source]

Orchestrates a grading run: find submissions, place the data, execute each notebook, run the assignment's checks and apply the review policy.

This is the only entry point the Streamlit UI and cli.py use. Construct it from a loaded Rubric (or with from_rubric_path); the assignment grader registered under rubric.id is selected automatically.

run(candidates: Iterable[SubmissionCandidate], session: GradingSession | None = None, progress_callback: ProgressCallback | None = None, cancel_event: threading.Event | None = None, preserve_overrides: dict[str, Any] | None = None, workdir_root: str | Path | None = None) -> GradingSession #[source]

Grade every candidate and return the saved session.

Submissions are graded one at a time. progress_callback receives a GradingProgress snapshot at every stage (a callback that raises never stops grading); setting cancel_event stops after the current submission. preserve_overrides is a snapshot from GradingSession.collect_overrides to re-apply on top of the fresh automatic scores. Working directories are deleted afterwards unless GraderSettings.keep_workdirs is set.

regrade(session: GradingSession, candidates: Iterable[SubmissionCandidate], preserve_overrides: bool = True, progress_callback: ProgressCallback | None = None, cancel_event: threading.Event | None = None) -> GradingSession #[source]

Grade the same candidates again into the same session id and directory.

With preserve_overrides (the default) every manual override is snapshotted first and restored on top of the new automatic scores.
